# Release v1.0.0

Initial independent matching application: dynamic-column XLS/XLSX import, exact/partial matching, explicit review, individual/combined and matched-only XLSX exports, dataset reset/reimport, staff login and user management.

Validation: 25 tests / 79 assertions passed on PHP 8.3 with SQLite. Frontend production build and Blade compilation passed. MySQL is the deployment target; a live MySQL server was not used in this validation.
