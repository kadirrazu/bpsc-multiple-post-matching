# Release v1.1.0

Rename the software to Multiple Post Matching System. Add accessible password visibility toggles to login, user create/edit and own-password forms. Restrict Operators to workspaces they created, including every direct view/mutation/export URL; administrators retain all-workspace access. Operators cannot change their own name/email/role/status through profile requests; only designation and password can change. Workspace-list headings are bold and all values except Workspace are centered/middle.

Run the new migration to add created_by. Existing workspaces have no stored creator history, so their owner remains null and only administrators can access them until a verified creator is assigned. Do not guess ownership or grant Operators access to unowned workspaces. New workspaces record the signed-in creator server-side.

Existing APP_NAME settings no longer override the product name. Root README title is supplied outside Paste-Replace for optional one-time manual updating. Validation: 34 PHP tests / 165 assertions passed on PHP 8.3 with SQLite; one Node password-toggle behavioral test and the production frontend build passed. Tests cover operator listing, every foreign-workspace view/mutation/export route, creator spoofing, admin/legacy access, profile tampering, own-password changes, and password-toggle rendering.
