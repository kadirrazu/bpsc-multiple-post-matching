# Release v1.1.2

Added workspace Edit/Delete actions, a title-edit form and a delete-confirmation page showing affected data counts. Workspace deletion atomically cascades to all its post/import/matching data. Operator ownership restrictions remain in force; other workspaces and users remain untouched. Existing foreign keys already support cascade deletion: no new migrations, dependencies or assets required. Root README excluded. Validation: 37 PHP tests / 195 assertions passed on PHP 8.3 with SQLite. Coverage verifies title edits retain creator/imports, invalid confirmation does not delete, confirmed deletion removes imported/review/person data, other workspaces/users survive, foreign Operators are blocked on all new endpoints, and Administrators can manage another owner’s workspace.
